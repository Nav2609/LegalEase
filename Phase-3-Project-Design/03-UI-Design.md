# 03 - UI Design

## Overview

The LegalEase user interface is designed using Streamlit with the goal of providing a simple and easy-to-follow document-generation workflow.

## Main Interface Sections

### 1. Application Title

The application displays the LegalEase name and provides a brief description of its purpose.

### 2. Document Type Selection

The user can select the type of legal document they want to generate.

### 3. Party Information

The interface provides fields for entering information about the parties involved in the document.

### 4. Terms and Conditions

The user can enter the relevant terms and conditions for the selected document.

### 5. Effective Date

The interface allows the user to specify the effective date of the document.

### 6. Generate Button

A generation button allows the user to submit the information and request an AI-generated document.

### 7. Document Preview

After successful generation, the application displays the generated document for review.

### 8. Download Options

The interface provides download options for:

- TXT
- DOCX
- PDF
