# 02 - Frontend Development

## Overview

The LegalEase frontend provides the user interface through which users enter legal document information, generate documents, preview the generated content, and download the final document.

The frontend is developed using Streamlit.

## Frontend Technology

The main frontend technologies are:

- Python
- Streamlit
- HTML/CSS components provided through Streamlit
