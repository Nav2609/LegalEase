# 01 - Development Environment

## Overview

The LegalEase development environment provides the tools and configuration required to develop and run the application locally.

## Programming Language

The project is developed using Python.

Python is used for:

- Frontend development
- Backend development
- AI integration
- Document generation
- Document export

## Development Tools

The project uses:

- Visual Studio Code or another code editor
- PowerShell / Terminal
- Git
- GitHub
- Python virtual environment

## Virtual Environment

A Python virtual environment is used to keep project dependencies isolated from the system Python installation.

The project uses a `.venv` directory for the virtual environment.

## Environment Configuration

Sensitive configuration values are stored in a `.env` file.

Examples include:

```text
GEMINI_API_KEY
GEMINI_MODEL
BACKEND_URL
