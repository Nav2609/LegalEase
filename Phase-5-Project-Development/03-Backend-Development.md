# 03 - Backend Development

## Overview

The LegalEase backend provides the API layer between the Streamlit frontend and the AI document generation system.

The backend is developed using FastAPI.

## Backend Technology

The main backend technologies are:

- Python
- FastAPI
- Pydantic
- Google Gemini API
