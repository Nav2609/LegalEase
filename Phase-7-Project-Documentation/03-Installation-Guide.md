# 03 - Installation Guide

## Overview

This guide explains how to set up and run the LegalEase application in a local development environment.

## Prerequisites

Before installing LegalEase, ensure that the following are available:

- Windows, Linux, or macOS
- Python 3.x
- Git
- Internet connection
- Google Gemini API key
