# 02 - Project Schedule

## Overview

The LegalEase project is divided into multiple phases so that development can be carried out in a structured manner.

## Project Phases

| Phase | Activity | Main Outcome |
|---|---|---|
| Phase 1 | Brainstorming and Ideation | Problem and solution identified |
| Phase 2 | Requirement Analysis | Requirements documented |
| Phase 3 | Project Design | System architecture and design defined |
| Phase 4 | Project Planning | Development plan prepared |
| Phase 5 | Project Development | Application implemented |
| Phase 6 | Project Testing | Application tested |
| Phase 7 | Project Documentation | Project documentation completed |
| Phase 8 | Project Demonstration | Final project demonstrated |
