# 02 - Demo Workflow

## Overview

The LegalEase demonstration follows a simple end-to-end workflow that shows how a user creates and exports an AI-assisted legal document.

## Complete Workflow

```text
Launch Backend
      ↓
Verify API
      ↓
Launch Streamlit Frontend
      ↓
Open Application
      ↓
Select Legal Document Type
      ↓
Enter Document Details
      ↓
Submit Request
      ↓
FastAPI Backend
      ↓
Gemini AI Generation
      ↓
Return Generated Document
      ↓
Review Document
      ↓
Choose Export Format
      ↓
Download Document
