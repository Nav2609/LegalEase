# 05 - Demo Checklist

## Before the Demonstration

- [ ] Project folder is available.
- [ ] Python environment is working.
- [ ] Required dependencies are installed.
- [ ] `.env` contains the required configuration.
- [ ] Gemini API key is valid.
- [ ] No API key or secret is visible on screen.
- [ ] Backend starts successfully.
- [ ] Frontend starts successfully.
- [ ] Browser opens the Streamlit application.

## Backend Verification

- [ ] FastAPI server is running.
- [ ] Backend root endpoint responds successfully.
- [ ] No critical backend errors are shown.
- [ ] Gemini connection is working.

## Frontend Verification

- [ ] Streamlit interface loads correctly.
- [ ] Document type selection works.
- [ ] Input fields work correctly.
- [ ] Generate button works.
- [ ] Generated document is displayed.

## Document Generation

- [ ] Sample information is ready.
- [ ] Sample information is fictional or anonymized.
- [ ] Document generation completes successfully.
- [ ] Generated content is readable.
- [ ] Important fields are present.
- [ ] Any placeholders are identified for review.

## Export Verification

- [ ] TXT export works.
- [ ] DOCX export works.
- [ ] PDF export works.
- [ ] Exported files open successfully.
- [ ] Exported content is readable.

## Presentation

- [ ] Project problem is explained.
- [ ] Proposed solution is explained.
- [ ] Objectives are presented.
- [ ] Technology stack is presented.
- [ ] System architecture is explained.
- [ ] Live demonstration is completed.
- [ ] Testing results are presented.
- [ ] Security practices are mentioned.
- [ ] Limitations are explained.
- [ ] Future enhancements are explained.

## Screenshots

- [ ] Startup screenshot captured.
- [ ] Main application screenshot captured.
- [ ] Document selection screenshot captured.
- [ ] User input screenshot captured.
- [ ] Generated document screenshot captured.
- [ ] Export screenshot captured.
- [ ] No sensitive information appears in screenshots.

## Final Check

- [ ] README is updated.
- [ ] All project phases are present.
- [ ] Documentation is complete.
- [ ] Git working tree is clean.
- [ ] Project can be run successfully from the documented instructions.
- [ ] Final presentation materials are ready.
