# 03 - Demo Screenshots

## Overview

Screenshots provide visual evidence of the LegalEase application's functionality and can be included in the final project report or presentation.

## Screenshot Guidelines

Each screenshot should clearly show the relevant application feature without exposing:

- API keys
- Passwords
- Personal credentials
- Private user information
- Unnecessary desktop information

Use fictional or anonymized information for demonstration screenshots.
