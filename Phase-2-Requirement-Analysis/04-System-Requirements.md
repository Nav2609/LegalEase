# 04 - System Requirements

## Overview

System requirements define the software, hardware, and external services required to develop and run LegalEase.

## Software Requirements

The project uses the following software and technologies:

- Python
- Streamlit
- FastAPI
- Google Gemini API
- `google-genai`
- `python-dotenv`
- `python-docx`
- ReportLab
- Git
- GitHub
- Modern web browser

## Frontend Requirements

The frontend requires:

- Streamlit
- Python
- Web browser

The frontend is responsible for collecting user input, displaying generated documents, and providing download options.

## Backend Requirements

The backend requires:

- FastAPI
- Python
- AI generation module
- Environment configuration

The backend processes requests from the frontend and communicates with the Gemini API.

## AI Service Requirement

A valid Gemini API key is required for AI-powered document generation.

The API key should be stored securely in an environment variable.

## Hardware Requirements

A standard computer capable of running Python and a modern web browser is sufficient for local development.

## Internet Requirement

An active internet connection is required for communication with the Gemini API.

## Storage Requirements

The project requires sufficient local storage for:

- Source code
- Python environment
- Project dependencies
- Generated documents

## Version Control

Git is used for version control and GitHub is used to host the project repository.
